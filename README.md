# Erik-Kristian Mäki-Fränti portfolio

Static portfolio site for GitHub Pages.

## Files

- `index.html` - the portfolio page
- `styles.css` - visual styling
- `assets/` - CV PDFs and image assets

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `portfolio`.
2. Upload everything inside this folder to the repository root.
3. In GitHub, open `Settings` -> `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select branch `main` and folder `/root`.
6. Save. GitHub will create a public site link after a short wait.

If the repository is named `yourusername.github.io`, the site address becomes:

`https://yourusername.github.io`

If the repository is named `portfolio`, the address is usually:

`https://yourusername.github.io/portfolio`
